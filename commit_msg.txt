[프로젝트 구조 및 파일 기능 요약]

1. 📂 주요 폴더 (Directories)
- backend/: 메인 서버(:8010) 및 AI 추론 서버(:8001)용 FastAPI 백엔드, DB/AI 파이프라인
- frontend/: 사용자 인터페이스 (React 18 + TypeScript + Vite)
- Pathology_model/: AI 모델 (Multi-stain/Multi-scale MIL, CTransPath) 연구 및 학습 코드
- AKI/: 머신러닝 연구 산출물 및 데이터셋 전처리 코드
- data/: WSI 이미지 및 데이터셋 보관 (버전관리 제외)
- static/: 데모 화면, 결과 그래프 등 정적 자원
- uploads/, pacs_cache/, analysis_results/: 사용자 업로드, PACS 캐시, 분석 결과물 디렉토리
- docs/: 프로젝트 가이드 및 추가 문서
- tests/: 코드 검증용 테스트 코드 (Pytest 등)
- utils/, scripts/: 데이터 전처리 등 개발 보조 스크립트

2. 🚀 주요 스크립트 및 실행 파일
- start_dev.bat: 개발 환경 자동 설정 및 프론트/백엔드/DB 시드 동시 구동 통합 런처
- stop_dev.bat: 구동된 서버 일괄 강제 종료 런처
- make_plots.py, make_ablation_plots.py: 결과 분석용 성능 그래프 생성 스크립트
- run_overnight_171.bat, run_train_wandb.ps1: AI 모델 장기 학습 및 모니터링 실행 스크립트

3. 📄 설정 및 문서 파일
- README.md: 프로젝트 아키텍처, 기능, 결과물 메인 소개 문서
- project_summary.md: 서버 실행 구조 및 설정 가이드라인 요약서
- conda_setup_guide.md, svn_ignore_guide.md: 환경 구성 및 SVN Ignore 설정 가이드
- pdf_config.json: PDF 자동 리포트 생성 설정
- mil_cv_cdss_v4_experiment_ctranspath.json: 최종 MIL 모델 CV 결과 데이터
- package.json, pytest.ini: Node 의존성 및 Pytest 환경 설정 파일

4. 📝 로그, 임시 및 기타 파일
- *.log (_8001_b.log, output.log 등): AI 추론, 시스템 감사, 오류 디버깅 관련 로그
